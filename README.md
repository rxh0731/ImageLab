# ImageLab

ImageLab 是用于碑文拓印、古籍扫描和手稿扫描的原生桌面去背景工具。只移除背景与杂点，保留文字掩膜内的原始 RGB 墨色；不生成文字区域多边形。

## 启动

双击 `start_imagelab.bat` 或 `start_imagelab_desktop.bat`，两个入口均启动 PySide6 桌面程序。脚本自动建立虚拟环境，缺少必要依赖时安装 `requirements.txt` 中的依赖。需要 Python 3.11 或更高版本。

## 操作流程

1. 选择原图路径和导出路径。只枚举指定路径下的图片，不包含子目录。
2. 选择处理模板，可手动调整参数、保存模板或另存为新模板。
3. 使用上一张、下一张或“跳至”查看图片。翻页不自动处理：有已有结果就显示并标明，没有结果时结果窗口留空。
4. 点击“处理当前图片”生成预览。可用橡皮擦修正结果，再点击“保存当前图片”导出。
5. 点击“自动批量处理”处理目录全部图片，按所选格式直接写入导出路径；已有相同目标文件则跳过。支持取消、单张进度、总体进度和耗时显示。

## 导出设置

- **TIF**：默认单页透明 RGBA TIFF，无损保存文字。勾选白底图层时写入 Photoshop 图层数据，包含上方文字层和最底部纯白层；不是两页 TIFF。
- **PSD**：文字笔画层保留透明背景，可勾选增加纯白底层。
- **PNG**：透明背景、无损保存，不支持独立白底图层。
- **JPG**：透明区域合成为白色。JPG 不支持透明和图层，且有损压缩，即使最高质量也无法逐像素保持墨色；需要精确保留时选择 PNG、TIF 或 PSD。

白底图层选项仅在 TIF、PSD 格式下可用。PSD 及含 Photoshop 图层的 TIF 目前单边最大支持 30000 像素，超出时会提示改用普通 TIF/PNG 或调整 DPI。

导出的文字图层以当前图片文件名命名（不含扩展名），例如 `字帖003.jpg` 的文字图层名为 `字帖003`；白底图层仍命名为“白底”。

未勾选“启用统一输出分辨率”时，处理结果保留原图像素尺寸和 DPI。勾选后按设定 DPI 实际重新采样；重新采样会改变像素网格。输出格式、白底层和分辨率规则均可保存到模板。

文件直接保存为 `导出路径/原文件名.所选扩展名`，不新建同名子目录。手动保存遇到已有目标文件会询问是否覆盖；保存失败时保留原文件。批量处理始终跳过已存在的目标文件，并阻止覆盖原图。

## 预览与橡皮擦

- `Alt + 鼠标滚轮`：以光标位置为中心缩放，不设固定最大倍率。
- `空格 + 鼠标左键拖动`、鼠标中键拖动：平移画布。
- 普通滚轮上下移动，水平侧滚轮左右移动。
- 结果窗口 `Ctrl + 左键点击/拖动`：按圆形光标范围擦除，修改区域变为透明，RGB 不改变。
- `Ctrl + 滚轮`：调整圆形橡皮擦大小。
- `Ctrl + Z`：撤销最近一次擦除，最多保留 20 次笔划。

两侧视图按物理尺寸（像素尺寸 / DPI）同步缩放、移动，便于比较不同分辨率的原图和结果。透明区域仅以白色预览。图片预览及放大后的高清图均异步读取；文字编辑像素也在后台准备。橡皮擦只更新局部像素和撤销记录，点击、拖动和松开鼠标时均不保存整图，点击保存按钮才导出。

去背景采用背景估计、文字掩膜筛选、原图笔画补全及纸张颜色约束。分析用的增强与降噪不写入文字 RGB。针对笔画孔洞和邻近背景残留的约束保持在掩膜中；批量处理不为未查看的图片生成预览，以减少耗时。

## 代码与验证

- `app/desktop.py`：原生界面、异步任务、视图同步和橡皮擦。
- `app/processing.py`：背景去除与笔画保留。
- `app/exporting.py`：四种格式的导出与图层读写。
- `templates/`：处理参数模板。
- `.preview_cache/`：临时预览和处理缓存。

运行回归测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

仓库中的 FastAPI 入口仅供接口调试，桌面版为主要入口。
