# ImageLab 界面调整方案（待确认）

本目录只包含设计效果图及生成脚本，不接入程序。效果图使用项目字帖001的图像素材；去背景内容、分字边界、识别文字、确认状态和耗时均为交互示意，不作为算法结果或性能评估。

## 整体布局

保持深色原生桌面软件。顶部两个工作区：“整页去背景”和“单字提取”，共享当前图片、原图路径与导出路径。右上角“任务中心”用于查看当前与历史任务的进度、耗时、成功/跳过/失败明细。

左侧以预览和校对为主，右侧以设置和执行为主。目录选择移到顶部公共栏，避免切换工作区后重复选择。效果图为1920×1200布局；较小窗口下右侧设置可滚动，单字放大预览可折叠，以保证画布与工具不重叠。

## 整页去背景

- 翻页或跳转只载入原图及已有处理结果，无结果时结果区域留空。
- 原图/处理结果仍按物理尺寸同步缩放和移动，保留现有快捷键与橡皮擦。
- 处理参数集中在右侧，常用参数直达，高级参数折叠。
- “处理当前图片”“保存当前图片”同排并区分颜色；批量和取消同排。
- 导出保持JPG/PNG/TIF/PSD、可选白底层及可选统一DPI；默认不重新采样。
- 只需要整页的用户可在此结束；“前往单字提取”进入下一步，不自动启动识别。

## 单字提取

- 首次进入无分字数据时，保留去背景预览，提示点击“分析当前页”；已有分字数据则载入保存状态。当前无去背景结果时提供返回处理按钮。
- 分析前选择横排/竖排及阅读顺序、边缘留白；文字识别为可选项。竖排支持列内上→下、列从右→左。
- 分字与OCR在后台执行，显示阶段进度和取消操作，不自动把OCR建议当作人工确认结果。
- 左上显示整页及互不相交的单字边界；多边形用于复杂邻接情况，边界与笔画保持留白。
- 蓝色为当前选中，绿色为已确认，橙色为待校对；状态同时有文字标识。
- 底部缩略图按导出顺序排列，可翻动列表、筛选待校对字；点击字框或卡片同步选择。
- 支持调整边界、合并、拆分、补框、删除；不对文字重新去杂，不改变原有RGB和Alpha。
- 右侧输入或修正文字及序号，实时预览文件名；“确认并选择下一个”支持连续校对。
- 修改阅读顺序时先预览新顺序，再确认重排，避免意外改名。重复文字依靠原图名和序号区分。
- 存在未保存的橡皮擦或分字校对修改时，翻页/离开提示保存、放弃或取消。重新去背景导致分字数据需要更新时先提示。

## 导出单字

- 单独的导出确认窗口，确认范围、保存位置、格式、留白、分辨率和命名预览。
- 默认当前页已确认单字；可扩展为所选字或已校对多页。未确认字不静默导出。
- 命名默认“文字-原文件名-三位序号”，如“住-字帖001-001.png”。三位是最小宽度，大于999时自然扩展。
- 用户可选择包含待校对项；空文字使用“未识别”占位，非法文件名字符需替换并显示实际名称。
- 跳过待校对项时保留原序号，便于回到整页定位，不悄悄重排。
- 裁切默认按原有边界与留白，不缩放笔画；另提供统一方形画布（只扩画布、居中）选项。
- 单字默认PNG，背景透明且无损。TIF/PSD可加最底部白底层，文字层名称为单字文件名（不含扩展名）。JPG白底合成且有损，界面提示格式限制。
- 保存位置显式可选，效果图示例“导出/单字”；按用户选择路径直接保存，不隐式创建同名子目录。
- 同名文件提供询问/跳过/覆盖，询问弹窗支持“本次后续同类情况参照执行”；不覆盖原图。
- 点击开始导出后显示单字进度、总进度、耗时及取消按钮，结束后给出结果摘要和打开目录入口。

## 推荐操作流程

选择路径 → 选择模板 → 手动处理整页 → 可选橡皮擦修正 → 保存整页（可选） → 进入单字提取 → 分字与识别 → 校对文字/字框/顺序 → 导出单字。

确认重点：是否采用两个工作区；是否接受先校对后导出的默认流程；单字列表的位置；命名与阅读顺序的默认规则。
